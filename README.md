# 아뜨랑스 신상품 반응 분석 시스템

자사몰 관리자 페이지에서 신상품 반응도 데이터를 **Playwright로 자동 추출**하고,  
**히어로 점수(100점 만점)** 로 상품을 분류·분석하는 MD 운영 도구입니다.

---

## 프로젝트 구조

```
newgoods-ai-report/
│
├── scripts/
│   ├── extract-newgoods.js     # Playwright 자동 추출 → data/newgoods-data.csv
│   └── analyze-newgoods.js     # CSV 분석 + 히어로 점수 계산 → reports/newgoods-report.md
│
├── data/
│   └── newgoods-data.csv       # 추출된 원본 데이터 (샘플 포함)
│
├── reports/
│   └── newgoods-report.md      # 생성된 분석 리포트 (샘플 포함)
│
├── analysis-prompt.md          # 분석 기준 및 운영 판단 로직 문서
├── .env.example                # 환경변수 설정 예시 (.env 파일 생성용)
├── package.json
└── README.md
```

> `score_analysis.js` / `score_analysis.py` — 루트에 위치한 구버전 분석 스크립트 (참고용)

## 설치 방법

### 1. 저장소 클론

```bash
git clone https://github.com/YOUR_USERNAME/newgoods-ai-report.git
cd newgoods-ai-report
```

### 2. 패키지 설치

```bash
npm install
```

### 3. Playwright 브라우저 설치

```bash
npx playwright install chromium
```

---

## 환경 설정

`.env.example`을 복사해서 `.env` 파일을 만들고 실제 로그인 정보를 입력합니다.

```bash
# Windows
copy .env.example .env

# Mac / Linux
cp .env.example .env
```

`.env` 파일 내용:

```env
SNFG_ID=관리자아이디
SNFG_PW=관리자비밀번호
HEADLESS=true
```

> `.env` 파일은 `.gitignore`에 포함되어 있어 GitHub에 업로드되지 않습니다.

## 실행 방법

### Step 1 — 데이터 추출

```bash
npm run extract
```

- 자사몰 신상품 반응도 페이지에 자동 접속
- 로그인 → 테이블 데이터 추출 → `data/newgoods-data.csv` 저장
- 세션 쿠키가 자동 저장되어 다음 실행 시 로그인 생략

**브라우저 화면을 보면서 실행 (로그인 문제 발생 시):**

```bash
npm run extract:visible
```

---

### Step 2 — 분석 리포트 생성

```bash
npm run analyze
```

- `data/newgoods-data.csv` 읽기
- 히어로 점수 계산 + 상품 상태 분석
- `reports/newgoods-report.md` 저장

---

### 추출 + 분석 한 번에 실행

```bash
# Windows PowerShell
npm run extract; npm run analyze

# Mac / Linux / Git Bash
npm run extract && npm run analyze
```

> PowerShell은 `&&` 대신 `;`를 사용해야 합니다.

## Playwright 자동 추출 흐름

```
실행 시작
    │
    ├─ 저장된 세션 쿠키(.session-cookies.json) 존재?
    │       ├─ YES → 쿠키 복원 후 페이지 접속
    │       └─ NO  → 신규 접속
    │
    ├─ 로그인 페이지 감지?
    │       ├─ YES (.env 자격증명 있음) → 자동 로그인
    │       ├─ YES (자격증명 없음, HEADLESS=false) → 브라우저에서 수동 로그인 대기
    │       └─ NO  → 이미 로그인된 상태, 그대로 진행
    │
    ├─ 세션 쿠키 저장 (.session-cookies.json)
    │
    ├─ 테이블 로드 대기 (networkidle)
    │
    ├─ 가장 데이터가 많은 <table> 선택
    │
    ├─ 헤더 텍스트 → 필드명 매핑
    │   (상품등록일, 상품명, 조회수, 장바구니수, 구매수,
    │    장바구니 비율, 구매 비율, 총 비율, 판매금액, 평균체류시간)
    │
    └─ CSV 변환 후 data/newgoods-data.csv 저장
```

## 분석 기준

`analysis-prompt.md`에 정의된 기준을 바탕으로 각 상품을 분석합니다.  
단일 지표가 아닌 **지표 간 조합**으로 문제 원인을 추정합니다.

| 패턴 | 해석 | 추정 원인 |
|------|------|-----------|
| 조회수 높음 + 장바구니 비율 낮음 | 상품 진입 후 이탈 높음 | 썸네일 미스매치, 가격 충격 |
| 장바구니 비율 높음 + 구매 비율 낮음 | 결제 직전 이탈 | 가격 부담, 배송비, 리뷰 부족 |
| 체류시간 높음 + 구매 비율 낮음 | 상세 열람 후 구매 결심 실패 | 상세페이지 설득력 부족 |
| 조회수 낮음 + 구매 비율 높음 | 노출 부족으로 매출 제한 | 광고 확대 시 폭발적 성장 가능 |

각 상품에 대해 다음 6개 항목이 자동 생성됩니다:

1. **상품 상태 요약** — 현재 상황 3줄 서술
2. **문제 원인 추정** — 데이터 패턴 기반 가설
3. **추천 운영 액션** — ACT-01 ~ ACT-11 중 해당 액션 선택
4. **우선순위** — 🔴 긴급 / 🟠 높음 / 🟡 보통 / 🟢 유지
5. **기대 효과** — 액션 실행 시 예상 변화
6. **히어로 점수** — 100점 만점 채점

## Hero Score (히어로 점수)

상품의 전체적인 퍼포먼스를 **100점 만점**으로 수치화합니다.

### 채점 기준

| 지표 | 배점 | 구간별 점수 |
|------|------|------------|
| 구매 비율 | 30점 | 5%↑: 30 / 3~5%: 24 / 2~3%: 18 / 1~2%: 12 / 0.5~1%: 6 / 미만: 0 |
| 장바구니 비율 | 20점 | 20%↑: 20 / 15~20%: 16 / 10~15%: 12 / 5~10%: 8 / 2~5%: 4 / 미만: 0 |
| 조회수 | 20점 | 2,000↑: 20 / 1,000~: 16 / 500~: 12 / 200~: 8 / 50~: 4 / 미만: 0 |
| 판매금액 | 20점 | 200만↑: 20 / 100만~: 16 / 50만~: 12 / 20만~: 8 / 5만~: 4 / 미만: 0 |
| 평균 체류시간 | 10점 | 55초↑: 10 / 45초~: 8 / 38초~: 6 / 30초~: 4 / 20초~: 2 / 미만: 0 |

### 등급 기준

| 점수 | 등급 | 운영 방향 |
|------|------|---------|
| 80 – 100점 | ⭐ HERO | 광고·메인 집중 투자. 전사 핵심 상품 |
| 60 – 79점 | 🔼 성장 가능 | 약점 보완 시 HERO 달성 가능. 집중 육성 |
| 40 – 59점 | ➡️ 관찰 필요 | 원인 분석 후 선별 개선 |
| 0 – 39점 | 🔽 개선 필요 | 상품 재검토 또는 소진 정리 |

### 운영 액션 코드

| 코드 | 액션 | 적용 조건 |
|------|------|---------|
| ACT-01 | 광고 확대 | 구매 비율 높음 + 조회수 낮음 |
| ACT-02 | 광고 중단 | 조회수 높음 + 전환 전무 |
| ACT-03 | 메인 노출 | 총 반응률 우수 |
| ACT-04 | 푸시 발송 | 장바구니 이탈자 다수 |
| ACT-05 | 리뷰 확보 | 장바구니 높음 + 구매 낮음 |
| ACT-06 | 상세페이지 수정 | 체류시간 높음 + 구매 낮음 |
| ACT-07 | 가격 점검 | 장바구니→구매 전환율 낮음 |
| ACT-08 | 재고 확보 | 판매 실적 우수 |
| ACT-09 | 긴급 소진 유도 | 저반응 상품 |
| ACT-10 | 코디 상품 연결 | 체류시간 높음 |
| ACT-11 | 외부몰 확장 | 자사몰 전환 낮음 + 상품 반응 우수 |

## 데이터 컬럼

| 컬럼 | 설명 |
|------|------|
| 상품등록일 | 상품이 등록된 날짜 |
